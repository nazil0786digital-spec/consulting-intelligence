# v0.3.0 — Phase 3 Pilot Quality and Reliability

## What users can do

- Review a visible quality checklist with every workspace evidence pack.
- See recent investigations in a read-only, workspace-scoped audit history.
- Mark an evidence pack helpful or needing review and provide an optional note.
- See aggregate pilot feedback counts without exposing individual feedback comments in the dashboard.

## Technical highlights

- Sanitized, version-controlled retrieval baseline exposed through `/v1/evaluations/baseline`.
- Deterministic quality checks for citation availability, context completeness, and mandatory human review.
- Tenant-scoped investigation history and feedback validation.
- Tenant-scoped aggregate feedback monitoring.

## Verification

- Automated: 16 API tests cover tenant isolation, document ingestion, issue analysis, evaluations, audit history, feedback, quality checks, and the pgvector column contract.
- Manual: Next.js production build passed.

## Known limitations

- The evaluation suite is intentionally small and uses only sanitized fixtures; it is not yet a pilot-scale labeled benchmark.
- No authentication or reviewer identity is available yet; this remains a local pilot workflow.
- Audit history records investigation metadata and evidence-source counts, not a full immutable event ledger.
- The product still performs no external actions.

## Next

Phase 4 begins with approval-driven integrations. The first integration work will remain read-only until user review and authorization boundaries are defined.
