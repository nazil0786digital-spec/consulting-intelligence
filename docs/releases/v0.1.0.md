# v0.1.0 — Phase 1: Evidence-Pack Proof of Concept

## What users can do

- Enter a sample consulting issue in a browser interface.
- Generate a structured evidence pack with verified information, a similar historical case, missing information, and a recommended next step.
- Review source excerpts and copy-ready Jira and client-response drafts.

## Technical highlights

- FastAPI preview API with typed evidence-pack contracts.
- Next.js investigation interface.
- Organization-scoped fixture corpus and rejection of unknown organizations.
- Local CORS policy connecting the interface to the API.

## Verification

- Automated: three API tests cover the evidence contract, organization isolation, and allowed local web origin.
- Manual: production UI build and local page smoke test passed.

## Known limitations

- Uses only a synthetic fixture corpus; documents are not uploaded or persisted yet.
- No sign-in, database, embeddings, semantic retrieval, or external integrations.
- Drafts are read-only proof-of-concept output; no persistence or approval history yet.

## Next

Phase 2 begins with organization-scoped persistence, document ingestion, chunking, retrieval, and real investigation records.
